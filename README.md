# GlassBoard-Skill

GlassBoard 玻璃板 v0.9.12 客户支持 AI Skill（WorkBuddy 格式）。

包含《GlassBoard 玻璃板客户详细说明书》v0.9.12（说明书版本 2026-10-17）完整内容，供 AI 作为唯一操作依据回答客户问题。

## 结构

- `SKILL.md` — skill 定义：触发场景、回答规则、检索顺序
- `references/manual-01-basics.md` — 第 01~11 章（基础、安装、界面、面板、分组、Dock、任务栏）
- `references/manual-02-features.md` — 第 12~23 章（主题、组件、时钟、闹钟、天气、音乐、备忘录、方案、备份、更新）
- `references/manual-03-troubleshooting.md` — 第 24~30 章（界面恢复、诊断、Q01~Q72、速查表、术语表）
