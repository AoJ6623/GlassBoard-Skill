# GlassBoard 玻璃板客户详细说明书（第 12~23 章）

## 12 主题玻璃材质和透明度

### 三类外观分别调整

大面板、Dock、桌面小组件有各自的玻璃与透明度设置。小组件共享部分基础材质设置；每个组件的文字颜色、文字透明度和无框状态可以单独 DIY。

先确定要修改的对象，再改相应设置。比如只想把时钟文字变白，进入时钟"外观 DIY"，不必把整个 Dock 的强调色改白。

### 两种百分比方向相反

| 设置 | 0 的含义 | 100 的含义 |
|---|---|---|
| 背景透明度 | 背景最实、最不透明 | 背景完全透明 |
| 文字不透明度 | 文字完全透明，看不见 | 文字完全可见 |

"透明度"和"不透明度"方向相反。文字消失时，把文字不透明度先调到 100；背景太实则增加背景透明度。把背景设为透明，也不代表所有边框、阴影和功能按钮会自动消失。

### 玻璃类型与颜色

可选磨砂玻璃、清透玻璃、亚克力、渐变玻璃。玻璃底色使用 #RRGGBB 六位色值，例如 #203040；输入后点击"应用色调"。留空可跟随当前主题。

组件文字色输入框的规则略有不同，允许带或不带 # 的六位色值。不要把玻璃底色框与组件文字色框混为一谈。

### 模糊反光纹理与阴影

模糊范围约 0–40，边缘高光约 0.2–2，反光和细纹理约 0–100，阴影可开关。背景越复杂、对比越高，同一参数看起来越不一样。

玻璃模糊会使用打开时的内存背景快照，并不等于持续实时折射整个动态桌面。使用动态壁纸时，不要把模糊背景没有逐帧同步当作所有材质都失效。

### 与壁纸软件搭配

可以让独立壁纸软件提供桌面背景，GlassBoard 提供 Dock 和组件。两者的性能和显示问题要分别判断。GlassBoard 不包含第三方壁纸插件、在线歌词服务或对其他插件全部样式的完整复刻。

### 一套好读的初始搭配

先把文字不透明度设为 100，开启轻微文字阴影；选与壁纸对比明显的文字颜色，再慢慢增加背景透明度。确认白天、夜间和不同壁纸画面都能看清后，再减少阴影或边框。

## 13 桌面组件的开启融合移动和锁定

### 当前有哪些组件

v0.9.12 提供时钟、天气、音乐、备忘录四类组件。它们可以分别开启或关闭，首次使用不应假定全部已经启用。

打开设置"桌面组件"，勾选需要的组件；也可以在系统托盘中选择"开启组件·时钟""开启组件·天气""开启组件·音乐""开启组件·备忘录"。

### A 到 D 是面板编号

A、B、C、D 表示组件容器，不是桌面页面、账号或四种皮肤。放到同一编号的组件会融合在一个面板里，分到不同编号就分开显示。

例如把时钟和天气都分到 A，就会一起移动；把音乐设为 B、备忘录设为 C，它们可单独摆放。使用"全部融合"或"全部分开"可以快速调整。

### 移动组件

1. 在"桌面组件"设置确认没有锁定组件位置。
2. 有框面板可抓住顶部拖动区域或标题拖动。
3. 时钟可尝试抓住时间文字拖动；无框组件可抓住非交互文字区域。
4. 放开后等待位置保存，再按需要开启锁定。

不要抓住音乐播放按钮或备忘录输入框来移动，这些区域保留点击、输入等功能。锁定组件位置是全局开关，会影响所有组件面板。

### 调整尺寸

有框面板可以用右下角调整尺寸，也可在"外观 DIY"中调面板宽度，范围约 240–1000，最终受显示器可用空间限制。面板最低宽度约 240，高度会受到内容和样式约束。

无框状态下可能没有可见缩放手柄，优先使用 DIY 宽度滑块。融合后内容太挤，先增加宽度或把组件拆开，不要假设组件一定会自动出现完整滚动条。

### 置顶和锁定的范围

组件置顶和组件位置锁定属于全局组件选项，不是每个时钟、天气各自独立的一套。各面板的位置、尺寸、背景透明度、控制按钮显示状态则会分别保存。

开启置顶后仍可能被某些独占全屏、受保护窗口或 Windows 系统界面覆盖，不能把"置顶"理解为能够压过所有系统窗口。

### 关闭组件与隐藏按钮

组件上的 × 关闭该组件，融合的其他组件可以继续保留。关闭不会自动删除备忘录内容或全部 DIY。重新启用相应组件即可找回。

右键菜单可隐藏或显示控制按钮；这与无框模式不同。找不到按钮时，尝试组件右键或回到设置"桌面组件"。

### 三种恢复入口的区别

| 操作 | 实际作用 |
|---|---|
| 重新打开已启用组件 | 重建当前已启用的组件，不主动把全部四类开启 |
| 开启全部组件／恢复并开启全部组件 | 把时钟、天气、音乐、备忘录全部开启 |
| 重置全部组件位置 | 清理面板布局和部分尺寸、透明度、按钮状态等覆盖值，不删除笔记内容 |

"重置全部组件位置"影响的范围可能比单纯坐标更大。重要搭配先保存外观方案或导出完整备份。

## 14 所有组件的文字颜色与无框 DIY

### 打开外观 DIY

在组件上右键，选择相应组件子菜单，再进入"外观 DIY"。有框时也可从"···"进入菜单。进入后通过下拉选择时钟、天气、音乐、备忘录，确认当前编辑对象。

### 修改文字颜色

1. 选择要修改的组件。
2. 从颜色预设中选择，或输入六位十六进制颜色。例如白色用 #FFFFFF，黑色用 #000000，浅蓝用 #A8D8FF；组件文字色也接受省略 # 的六位写法。
3. 点击"应用色值"。
4. 把文字不透明度调整到需要的值，首次建议 100。
5. 切回桌面，查看在实际壁纸上的对比度。

无效颜色不会成为可靠的设置。只输入色值而没有点击应用，可能仍看到旧颜色。

### 文字阴影

文字阴影帮助浅色字从浅色壁纸中分离。无框大字时钟建议先开启，再按实际效果决定是否关闭。阴影不是背景框，开启阴影不意味着必须保留组件外壳。

### 无框模式

1. 在该组件"外观 DIY"打开无框，或在组件右键菜单切换"无框模式"。
2. 按需要显示或隐藏控制按钮。
3. 调整文字色与宽度，保证内容可读。
4. 解除全局组件锁定后，抓非交互文字区域移动。

无框主要移除装饰性外壳、边缘和相关背景，不会取消所有功能控件。备忘录仍需输入区域和按钮，天气仍可能保留天气符号、刷新等内容，音乐播放按钮仍可以操作。

### 融合面板里的无框规则

同一面板内有组件开启无框时，共享外壳可能被移除；其他仍设为有框的组件卡片可以保留自己的边缘。因此想让一组融合组件完全简洁，可逐个开启无框，或使用"无框状态应用到全部组件"。

如果只想时钟自由摆放，不想影响旁边备忘录的外观，先把它们分配到不同面板编号。

### 批量应用按钮

- "配色应用到全部组件"复制文字颜色、文字不透明度和阴影，不会把时钟字体或音乐按钮样式一并覆盖。
- "无框状态应用到全部组件"只复制无框状态。
- "恢复本组件默认外观"恢复当前组件的样式设置，不删除备忘录内容，也不是把所有组件搬回初始位置。

### 文字看不见的恢复步骤

先回到设置或其他可见组件的 DIY，选中目标组件，把文字不透明度调到 100，换成与壁纸对比明显的颜色，关闭无框或恢复默认外观。不要把背景透明度调到 0 当作文字透明度修复。

## 15 时钟的十三种样式与字体

### 切换样式

开启时钟后进入时钟"外观 DIY"，从样式下拉框选择。切换后看实际桌面效果，再调整宽度、字体大小和日期开关。

| 样式名称 | 视觉特点 | 适合的搭配 |
|---|---|---|
| 经典时间 | 直接展示常用时间信息 | 初次使用、强调清晰易读 |
| 手写星期叠字 | 星期与时间形成叠字构图 | 留白较多的壁纸 |
| 极简大数字 | 以大号时间数字为主 | 大屏、无框桌面 |
| 星期与日期 | 强调星期和日期组合 | 需要随时看日期的桌面 |
| 分栏数字 | 把时间数字分栏排布 | 有秩序感的布局 |
| 宽距星期 | 字母与星期留出较宽间距 | 横向留白区域 |
| 日期海报 | 时间日期组合成海报式排版 | 简洁背景或整组主题 |
| 纵向数字 | 数字纵向组织 | 较窄的侧边区域 |
| 细线指针 | 简洁指针式表盘 | 喜欢模拟钟面的用户 |
| 日程轨道 | 以轨道或环形表现当天时间进度 | 想看一天推进程度 |
| 衬线杂志 | 带有杂志排版感 | 简洁照片与衬线字体搭配 |
| 等宽电子 | 等宽数字的电子感 | 科技、终端风格壁纸 |
| 横向日历 | 横向日期与时间组合 | 桌面上方或横向区域 |

"日程轨道"展示当前本地一天的时间推进，不读取待办或日历日程。"分栏数字"是排版风格，不代表持续翻页动画。"细线指针"没有可承诺的秒针连续扫动。

### 无框推荐效果

点击"使用无框推荐效果"可快速启用无框和文字阴影。没有自定义文字颜色时，会采用推荐的白色；已有自定义颜色时不会强制覆盖。

如原来选择了深色文字，点击推荐效果后仍是深色，属于保留个人设置，可手动改成白色。

### 更换字体

1. 在时钟 DIY 中选择字体，或在对应字体输入框填写已安装的字体名。
2. 点击"应用字体"。选择列表项后仍应确认应用。
3. 检查时间数字、中文日期、英文星期是否都能正常显示。
4. 调整字体大小，范围约 28–100。

软件不会自动下载字体。某些字体不含中文或特定数字，系统会回退到其他字体；某些样式自身使用字号比例，同一数值在不同样式里看起来大小不同。

### 日期与十二二十四小时制

使用"显示日期"和 24 小时制相关开关。部分样式中的星期属于构图的一部分，关闭日期不一定移除所有星期图层。个别样式使用英文星期作为设计元素，不代表系统语言或天气语言出错。

时间来自 Windows 本地时间和时区。时间不正确时先检查 Windows 日期、时间、时区和自动同步设置。当前没有独立世界时区选择器、任意拆分拖动的时分图层或所有样式的秒数显示选项。

### 两套示例

- 简洁大字：选"极简大数字"→启用无框→白色文字→文字不透明度 100→轻微阴影→按壁纸留白调整宽度和字号→锁定组件位置。
- 细线表盘：选"细线指针"→先保留可读的文字和背景对比→调整宽度→选择是否无框→放在不遮挡桌面操作的区域。不要用有无秒针动画判断表盘是否正常。

## 16 闹钟和倒计时

### 打开提醒窗口

在时钟右键菜单选择"闹钟与倒计时"。提醒功能依赖 GlassBoard 正在运行，不等同于 Windows 独立闹钟服务。

### 添加闹钟

1. 以 24 小时 HH:mm 输入时间，例如 07:30、18:05。
2. 填写标签，方便提醒时知道事项。
3. 根据需要勾选"每天重复"；不勾选时为单次提醒。
4. 点击"添加闹钟"。
5. 在列表中确认已添加且处于开启状态。

即使时钟显示十二小时制，闹钟输入仍使用 24 小时格式。当天该时间已过去时，会安排到下一天对应时间。可在列表启用、关闭或删除已选闹钟，最多保存约 50 条。

### 倒计时

输入 1–1440 的整数分钟，点击开始。运行中可暂停、继续或取消。它按分钟设置，不是任意秒数输入器。

### 提醒出现时

到时会出现提醒窗口，并使用系统提示声音；声音可能约每 2 秒提示一次，最多约 30 秒。点击"知道了"关闭，或"稍后 5 分钟"延后提醒。

系统音量、声音方案和设备状态会影响能否听见。当前没有让用户选择任意 MP3 作为闹铃的操作入口。

### 提醒生效的条件

软件应持续运行，电脑应保持唤醒。关闭时钟组件不等于关闭提醒服务，但退出整个 GlassBoard、关机、休眠或系统睡眠期间不能保证按时弹出；软件没有唤醒电脑的保证。

重要事项建议同时使用自己可靠的提醒方式。排查时先确认 Windows 时间和软件运行状态，再查看闹钟开启与否，避免反复添加重复提醒。

## 17 天气组件的设置和排查

### 第一次设置城市

1. 在设置"桌面组件"开启天气。
2. 找到天气城市输入框，输入城市，例如"杭州"。
3. 点击"应用天气城市"。
4. 等待联网查询完成，观察城市标题、天气描述、温度和更新提示。
5. 必要时在天气组件使用刷新按钮重试。

只在输入框中写城市但未点击应用，组件可能仍查询旧城市。天气不是通过 GPS 自动定位，不能仅凭当前人所在位置推断软件应该自动切换城市。

### 输入城市的建议

中文城市会进行部分省市后缀处理，但同名地点或小地区仍可能歧义。可以尝试"城市,国家或省州"，也可使用"纬度,经度"，纬度在前、经度在后。

例如换成较明确的英文城市名，或使用自己确认过的坐标。不要交换经纬度。城市场站名和用户输入可能不同，标题保留输入名也不能证明数据一定来自预期地点，应结合温度、天气和地理位置核对。

### 数据来源与刷新

天气优先使用 Open-Meteo，必要时尝试 wttr.in 备用服务。成功后通常约 30 分钟自动刷新；失败后会逐步重试，间隔可能从约 30 秒增加到数分钟。

查询需要等待网络与服务超时，连续点击刷新不一定更快。近期成功数据可能在本次运行中继续显示，并带上次数据相关提示；看到温度并不等于刚刚查询成功。

### 看懂信息

温度为摄氏度，风速以 km/h 等界面标示单位为准。常见英文天气描述会尝试转换为中文，备用服务也会请求中文；上游文本和罕见天气代码仍可能影响显示。

未知天气通常使用通用云类符号，不应仅凭一个图标判断天气服务完全准确。当前手册不提供不存在的空气质量、逐小时图、七日预报界面入口。

### 城市错误或天气不更新

1. 先确认已点击"应用天气城市"，不是只改输入文字。
2. 确认电脑可以联网；尝试一个明确的大城市作为对照。
3. 手动刷新一次，并等待一轮查询完成。
4. 同名城市改用更明确的位置或正确经纬度。
5. 看是否提示旧数据或错误，记录完整文字与时间。
6. 仍失败时提供城市输入、组件截图和相关诊断信息。

不要把"更新检查里的代理模式"直接当成天气专用代理开关。不同联网功能的路径和服务可能不同。不要为了天气一项先关闭安全软件或修改系统证书。

## 18 音乐组件的系统模式与本地模式

### 当前直接可见的控制

音乐组件显示封面或替代图、标题、歌手或来源状态，以及上一首、播放或暂停、下一首。按钮外观可以 DIY，但功能取决于当前模式和播放器支持。

v0.9.12 当前简洁界面没有可以按本手册操作的进度拖动条、音量加减按钮、随机播放或循环切换按钮。某些历史文字或旧截图可能提到这些能力，不能据此虚构当前入口。

### 系统音乐模式

1. 在音乐组件右键菜单选择"系统音乐模式"。
2. 打开支持 Windows 系统媒体会话的播放器，先正常播放一首歌。
3. 等待组件读取标题、歌手和封面。
4. 点击播放或暂停、上一首、下一首，核对播放器是否响应。

系统模式通过 Windows 媒体会话读取信息，不是录音识曲，也不会识别电脑发出的所有声音。部分网页视频或浏览器内容也可能成为当前媒体来源；某些播放器不提供全部信息或控制能力。

多个播放器同时打开时，当前来源可能与你预想不同。先暂停或关闭不需要的来源，用单一播放器对照，再判断是否为玻璃板问题。

### 系统模式没内容怎么办

确认播放器本身正在播放，不只停留在歌单页；确认它支持系统媒体信息。保持音乐组件开启并可见，等候一次读取。播放时读取较频繁，暂停、无会话或组件隐藏时会放慢，不保证每个状态都瞬时更新。

右键"查看音乐读取状态"，保留其中的版本路径、后端、来源、元数据、封面和错误信息。当前诊断比旧截图里的报错更有参考价值，不要仅凭过去"找不到脚本"的提示就认定新版本仍缺同一文件。

### 本地音乐模式

1. 右键音乐组件，选择"本地音乐模式"。
2. 使用"添加音乐"选择本地音频文件。
3. 打开"播放列表"，检查歌曲是否已经加入。
4. 双击一首，或选中后点击"播放已选"。
5. 使用组件上的上一首、播放或暂停、下一首控制。

文件选择支持 MP3、WAV、WMA、M4A、AAC、FLAC 等常见扩展名，实际能否解码仍取决于 Windows 媒体能力及文件本身。支持选中某种后缀不代表所有编码组合都能播放。

### 本地播放列表和音量

播放列表窗口可添加、播放已选、移除已选。移除的是列表引用，不删除磁盘上的音频文件。文件移动后，需要重新添加正确路径。

本地音量在设置"桌面组件"的"本地音乐音量"调整，范围为 0–1。该设置用于本地播放，不等于修改其他播放器音量或 Windows 主音量。

启动软件不会自动强制播放本地音乐。关闭音乐组件会停止并释放其本地播放；系统播放器属于独立程序，关闭组件不等于退出播放器。

### 封面与状态

右键可控制"自动补充音乐封面"。播放器没有提供专辑封面时，可能显示来源图标或替代图。不要把替代图误认为歌曲封面一定匹配。

当前没有内置在线音乐搜索、登录会员、歌词下载、滚动歌词或第三方插件授权功能。希望使用这些内容，应在独立播放器中完成，再看其系统媒体信息能否被读取。

### 五种按钮样式

进入音乐"外观 DIY"，选择经典圆形、极简线性、实心图标、圆角方形、玻璃胶囊。样式改变按钮形状和视觉，仍是同样的上一首、播放或暂停、下一首。

想只改按钮样式而保留其他组件配色，不必点击"配色应用到全部组件"。样式过小或与壁纸对比不足时，调整宽度和文字色后再判断可读性。

## 19 备忘录的记录保存和导出

### 新建与切换

开启备忘录组件，使用新建入口建立笔记，填写标题和正文；通过笔记下拉列表切换不同笔记。标题最多约 120 个字符。

### 自动保存

输入停止后约 0.65 秒自动保存，底部状态会提供保存反馈。切换笔记和正常退出会尝试写入待保存内容。输入完成后稍等，确认保存状态，再退出程序。

备忘录保存在本机配置内，不会因为关闭组件就删除，也不会自动同步到另一台电脑或另一个 Windows 账号。重要内容仍建议定期完整备份或单独导出。

### 清单按钮的含义

"清单"用于插入类似"☐ "的文本标记，便于写条目。它不是带独立任务状态、截止日期和通知的任务管理系统，不能据此承诺点击方框即可完成所有清单管理。

### 导出 TXT

选中需要的笔记，使用"导出"保存为 TXT。单篇导出用于阅读、分享或转到别的软件，完整备份用于连同其他设置一起迁移。

长笔记在小面板中不便查看时，先增加尺寸或导出阅读。不要假定组件提供 Word 排版、全文检索、云同步或 Markdown 实时渲染。

### 删除笔记

删除需要确认。确认前核对当前标题，重要内容先导出。当前没有供客户依赖的笔记回收站；大面板 Ctrl+Z 也不是笔记删除的恢复途径。

数据文件具有备份和损坏保护机制，但它们不是"所有误删都能恢复"的保证。遇到内容异常，先停止反复编辑，备份配置，再按诊断信息处理。

## 20 保存和分享外观方案

### 方案适合什么

外观方案用于保存一套桌面搭配，便于切换或分享。可从大面板"更多"、系统托盘或设置"面板与主题"中的"外观方案"进入。

### 保存当前方案

1. 先把主题、Dock、组件、入口和分组整理到满意状态。
2. 打开"外观方案"。
3. 输入容易辨认的名称，例如"白色极简时钟"或"工作桌面"。
4. 点击"保存当前"。
5. 在列表中确认名称出现。

### 应用导入与导出

选中已有方案，点击"应用方案"。导出会得到方案 JSON，可用于分享；导入时选择可信且格式正确的方案文件，再核对应用结果。删除方案是删除保存的搭配，不等于卸载软件。

方案可以包含主题、Dock 位置与混合顺序、入口及分组关系、图标大小、组件样式等。应用时会尽量保留后来新增的入口，保留当前快捷键和工作区；不会把当前笔记正文替换成别人的笔记。

### 分享的边界

方案不是完整备份，也不打包真实软件、文档、壁纸或音乐。对方电脑没有同路径软件时，相应入口不能凭空运行。自定义图标存在大小限制，单图约 512 KB、方案文件约 5 MB，过大的素材可能无法随方案完整携带。

分享前检查入口名称和路径是否包含不想公开的信息。需要把自己的全部数据迁移到新电脑，用第 22 章的完整备份。

## 21 工作区的一键打开

### 工作区是什么

工作区是一组需要一起打开的软件、文件夹和文档。例如"剪辑"工作区可以包含剪辑软件、素材目录、文稿和音乐目录。

它负责依次打开入口，不负责自动排列其他软件的窗口、不复制工程文件，也不承诺退出工作区时关闭所有应用。

### 建立工作区

1. 从大面板"更多"进入"工作区"，或从托盘进入"工作区管理"；设置中也可找到创作工作区入口。
2. 新建工作区并输入名称。
3. 在候选入口中勾选需要的软件、文件夹或文档。
4. 使用"保存工作区"。
5. 选择该工作区，点击"打开已选"，检查每个入口是否正确。

需要的文件还未在玻璃板入口库中时，先按第 06 章添加。全选、取消全选只影响当前选择，不会复制真实文件。

### 日常打开与维护

可从托盘"打开工作区·名称"快速启动。软件会尽量跳过已经识别为运行中的程序，并分批拉开启动间隔；特殊启动器和文件关联应用仍可能出现重复窗口。

项目换路径后，更新入口和工作区选择；换电脑时，先保证真实工程文件和应用已正确安装。工作区的保存不能替代项目文件备份。

## 22 完整备份迁移与历史找回

### 什么时候应备份

大规模整理前、恢复其他人的布局前、换电脑前、升级前、准备清理配置前，以及记录了重要笔记后。备份建议另存到独立目录或自己的可靠备份位置，不要只留在准备删除的程序目录里。

### 导出完整备份

1. 打开设置"通用"的完整备份与恢复，或大面板"更多"中的"导出完整备份"。
2. 选择保存位置，生成 .gbbackup 文件。
3. 检查文件确实生成，保留一个容易辨认的日期名称。
4. 重要数据同时保留原始软件、文档和音乐的独立备份。

完整备份包含玻璃板的布局、入口分组、固定项、设置、快捷键、组件、笔记、方案、自定义图标等个人数据。它不包含应用安装程序、真实文档、项目、音乐或桌面壁纸。

### 恢复完整备份

1. 先导出当前状态，避免覆盖后反悔。
2. 选择"恢复完整备份"，选中对应 .gbbackup。
3. 阅读确认提示，确认来源和目标。
4. 恢复后核对分组、Dock、组件、笔记及快捷键。
5. 如果出现路径失效，在本机重新关联真实文件或软件。

恢复会改变当前配置并清空相关撤销历史。程序会尝试在配置的 backups 目录保存恢复前副本；快捷键冲突时可能保留原有可用设置。不要把自动保护副本当作跳过手工备份的理由。

### 换电脑的建议顺序

旧电脑导出完整备份 → 把真实文档、工程和音乐另外迁移 → 新电脑安装需要的软件 → 解压完整 GlassBoard 用户包 → 启动后恢复备份 → 逐项修复不一致的入口路径 → 重新确认开机启动与快捷键。

开机启动是当前电脑和程序路径相关设置，迁移后需要重新检查。外观方案适合搭配分享，完整备份更适合自己的数据迁移。

### 找回旧版入口与分组

设置"通用"中使用"找回旧版入口与分组"。软件会读取可用历史和备份，列出候选内容；核对后合并需要找回的项目，尽量保留当前 DIY。

被标记为曾经主动删除的入口通常不会默认勾选，避免把你特意清理的内容全部带回。没有历史文件、历史已被清理或真实应用已经卸载时，不能保证找回可运行入口。

### 配置保护机制

配置采用临时写入、有效副本和历史快照等保护，常见副本后缀包括 .last-good、.previous；布局历史快照有数量上限，升级也可能建立快照。笔记另有自身备份与损坏保护。

这些机制用于降低异常写入造成的损失，不是无期限版本库。普通用户优先使用界面的备份恢复和找回工具，不建议直接编辑 JSON。确需人工处理时，先正常退出、复制整个配置目录，再由了解格式的人操作。

## 23 开机启动在线更新与卸载

### 开机启动

在设置"通用"按需开启。该选项不是所有用户默认启用；Windows 启动管理或系统策略也可能影响结果。

移动程序目录后，原开机启动路径可能失效。先确认新目录可正常运行，再在新位置关闭并重新开启该选项。不要同时留下多个旧版本启动入口。

### 查看真实版本

在程序目录找到 GlassBoard.exe，右键"属性"，查看"详细信息"中的文件版本。v0.9.12 的文件版本对应 0.9.12.0。

如果桌面或任务栏快捷方式仍指向旧目录，即使下载了新版也可能继续运行旧版。先从托盘退出旧实例，再从新目录启动，并核对路径与版本。

### 手动检查更新

打开设置"通用"，使用"立即检查"。自动检查属于可选设置，默认不应假定已经开启；启用后通常限制为每日成功检查一次，手动检查不依赖当天是否自动检查过。

更新只会按发布索引识别较高版本的用户运行包，源码包不作为普通更新包。项目发布地址为 https://github.com/SENLIN-SAMA/win.-，是否有更新以实际发布状态为准。

### 网络连接方式

更新支持系统代理或直接连接相关选项。网络失败时先看连接诊断，尝试适合当前网络的方式，再检查是否能访问发布页面。这个设置不能被当作所有天气、播放器流量的统一代理开关。

不要为更新失败关闭 HTTPS 验证或下载来历不明的替代 EXE。发布页面可访问而自动检查失败时，保留诊断文字，必要时完整下载官方用户包进行手动更新。

### 在线安装的大致过程

确认更新 → 下载 → 校验大小和 SHA-256 → 建立保护备份 → 调用更新助手 → 退出并替换程序文件 → 重新启动。下载阶段可按界面提供的方式取消；进入替换阶段不要自行断电、移动目录或随意删除助手文件。

程序目录需要可写，完整包中的更新助手需要保留。失败时先保留现场；更新任务目录中的结果文件和程序备份可供支持人员判断，不建议用户随意拼接不同版本文件。

### 手动更新

1. 正常退出正在运行的 GlassBoard。
2. 导出或保留现有配置备份。
3. 把新版用户包完整解压到明确目录，避免新旧 DLL 混用。
4. 从新版目录运行 GlassBoard.exe，核对版本和个人数据。
5. 更新桌面快捷方式与开机启动路径。

不要只用新 EXE 覆盖旧目录里的一个文件。个人配置默认共用，不必为了常规升级先删除配置文件夹。

### 卸载或暂时停用

暂时停用：托盘正常退出，需要时再启动。卸载：先关闭开机启动并正常退出，确认任务栏和桌面恢复，再删除程序文件夹及不再需要的快捷方式。

个人配置单独保留在本机用户目录。只有明确要彻底清除个人数据、并已备份重要笔记和布局时，才考虑清理配置；不要把这作为普通故障修复的第一步。
