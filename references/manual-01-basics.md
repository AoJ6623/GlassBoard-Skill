## 03 软件用途与第一次使用

### 玻璃板是什么

GlassBoard 是 Windows 桌面工具，包含应用大面板、Dock、桌面组件和相关外观设置。它把程序、文件、文件夹的入口整理在一起，并提供时钟、天气、音乐、备忘录四类组件。玻璃板上的制作水印为"抖音 森霖Sama 制作"。

它保存的是程序或文件的入口和布局。把软件加入面板并不等于安装软件；把入口移除也不等于卸载软件。实际文件仍保留在原来的磁盘位置。

### 运行条件

- 面向 Windows 10、Windows 11 桌面环境，需要 .NET Framework 4.8 运行环境。
- 系统音乐读取依赖 Windows 系统媒体接口以及播放器配合，建议在 Windows 10 1809 或更新版本、Windows 11 上使用。
- 天气、在线检查更新和联网播放器需要相应网络连接。本地入口、分组、时钟和备忘录等功能不要求登录账号。
- 显示效果受 Windows、显卡、DPI 缩放和桌面背景影响。多显示器和部分全屏应用中的行为，需要以实际电脑表现为准。

### 正确解压和启动

1. 获取 GlassBoard v0.9.12 的用户运行包。源码包主要供开发者使用，客户通常选择用户包。
2. 把 ZIP 完整解压到一个固定、可写入的文件夹。例如自己创建的软件目录。
3. 保留解压出来的完整文件结构，包括 DLL、lib、脚本和更新程序。不要只复制一个 EXE。
4. 双击 GlassBoard.exe，或双击 Start.cmd。
5. 看看屏幕底部是否出现 Dock，以及右下角系统托盘是否出现 GlassBoard 图标。托盘图标可能被 Windows 收在向上箭头里面。
6. 如果首次导入了开始菜单应用，稍等片刻再整理；首次出现的程序数量与本机安装情况有关。

不要在 ZIP 预览窗口内直接运行。不要把每次启动位置都放在临时解压目录里，否则快捷方式、开机启动和更新路径容易不一致。

### 建议的首次配置顺序

1. 打开设置，先选择喜欢的主题与基础透明度。
2. 添加最常用的软件，固定几个到 Dock。
3. 再开启时钟、天气等需要的组件，不必一次开启全部。
4. 调整各组件位置、宽度、文字颜色和是否无框。
5. 确认快捷键没有与其他软件冲突。
6. 导出一次完整备份，再按需要启用开机启动。

### 配置保存在什么地方

程序文件夹保存运行文件；个人设置默认保存在 `%LOCALAPPDATA%\GlassBoard`。可以在系统托盘菜单中点击"打开配置文件夹"。

这意味着：更换程序文件夹后，通常仍会读取同一个 Windows 用户的原有配置；单纯删除程序文件夹通常不会删除个人配置。迁移到另一台电脑时，应使用完整备份，不能只复制程序文件夹就认为所有布局和笔记已经迁移。

### 正常退出

在系统托盘中右键 GlassBoard，选择"退出 GlassBoard"。关闭大面板只是收起面板，不等于退出程序；关闭一个组件也只是关闭该组件。

正常退出会保存必要状态，并尝试恢复由软件接管的任务栏和桌面图标状态。遇到异常退出后任务栏没有回来，使用第 24 章的恢复方法。

## 04 认识界面和设置入口

### 四个常用区域

| 名称 | 看起来是什么 | 主要作用 |
|---|---|---|
| Dock | 桌面底部的一排入口 | 打开软件、切换窗口、进入大面板及系统快捷入口 |
| 大面板 | 展开的应用图标面板 | 搜索、分组、批量整理、添加程序和文件 |
| 桌面组件 | 时钟、天气、音乐、备忘录小窗口 | 展示信息、媒体控制、记事与提醒 |
| 系统托盘 | Windows 右下角图标区 | 打开设置、恢复桌面、控制组件、退出程序 |

"此电脑"打开 Windows 文件资源管理器中的电脑位置。"设置"齿轮打开 GlassBoard 设置。电源和网络入口提供 Windows 相关操作，不是普通的软件固定项。

### 打开设置的五种方法

1. 点击 Dock 上的设置齿轮，前提是该图标没有被关闭。
2. 在 Dock 空白处右键，选择"外观设置"。
3. 在大面板右上角点击齿轮，提示为"外观、组件与快捷键"。
4. 右键系统托盘图标，选择"外观与快捷键"。
5. 使用默认全局快捷键 Ctrl+Alt+S，前提是该快捷键启用且没有冲突。

把 Dock 设置图标关闭后，其他入口仍可使用。还可以在 Dock 右键菜单中选择"显示 Dock 设置图标"找回它。

### 六个设置页面

| 页面 | 适合调整什么 |
|---|---|
| 面板与主题 | 面板主题、玻璃外观、尺寸、位置与相关方案入口 |
| Dock DIY | Dock 尺寸、间距、位置、自动隐藏、系统图标等 |
| 快捷键与开关 | 快捷键及任务栏、桌面图标相关开关 |
| 桌面组件 | 四类组件开关、布局、时钟、天气、音乐等 |
| 通用 | 开机启动、更新、备份恢复、旧版入口找回等 |
| 支持创作者 | 作者支持相关内容 |

大部分外观开关调整后会立即保存。快捷键修改要点击"保存快捷键并完成"后才正式应用，不能只改输入框就关闭窗口。

## 05 大面板的打开搜索和布局

### 展开与收起

点击 Dock 的应用面板按钮，或使用 Ctrl+Alt+Space，也可以从系统托盘选择"打开应用面板"。展开后可用 Esc、右上角关闭按钮或再次点击 Dock 面板按钮收起。

启动某个程序后，大面板会收起。默认点击外部桌面不自动收起，便于从桌面往里拖入文件。需要点击桌面就收起时，在设置中启用"点击外部自动收起大面板"。

### 搜索和翻页

1. 展开大面板，确认搜索栏可见。
2. 输入软件名、中文名称或若干关键词。空格分开的词会共同参与筛选。
3. 查看结果，按 Enter 可以打开第一条匹配入口。
4. 内容超过一页时，使用底部翻页按钮或 PageUp、PageDown。

搜索会与当前分组一起筛选。例如当前在"游戏"分组，搜索办公软件可能没有结果，先切到"全部"。隐藏搜索栏时会清空当前搜索内容。

### 图标大小间距与面板尺寸

- 图标大小滑块范围为 28–80。
- 大面板"···"中的"图标间距与默认大小"可调整图标间距，范围 0–20；默认图标大小 48、间距 5。
- 面板尺寸预设包括"舒适·中号""宽阔·大号""铺满·全屏"。
- 允许调整时，可用顶部拖动区域移动面板，用右下角调整尺寸；锁定或重置在"面板与主题"中操作。
- 面板图标大小与 Dock 图标大小是两套设置。调整其中一项，不代表另一项也会变化。

### 隐藏分组栏会怎样

隐藏分组栏后，大面板显示全部入口，同时隐藏分组文件夹区域；原有分组并未删除。重新显示分组栏即可继续使用。

### 常用右键菜单

软件或文件入口右键可看到"打开""打开文件所在位置""文件属性""固定到 Dock"或"取消 Dock 固定""修改名称与图标""移动到分组""移除入口"等。大面板入口还可使用前移、后移操作。

遇到启动失败，先用"打开文件所在位置"检查原文件是否还存在，再看第 27 章的入口故障问答。

## 06 添加软件文件文件夹与自定义图标

### 方法一：直接拖入

从桌面、文件资源管理器或大面板中拖动入口。拖到大面板可以添加；拖到 Dock 可以固定。拖动只建立入口，不会把原文件从原位置搬走。

如果大面板总在拖入前消失，关闭"点击外部自动收起大面板"，再从桌面拖入。

### 方法二：批量添加窗口

点击大面板"+ 批量添加"，或使用 Ctrl+Alt+A。按需要选择来源：

| 按钮 | 作用 | 常见用途 |
|---|---|---|
| 选择多个文件 | 手动选择若干入口或文件 | EXE、快捷方式、文档等 |
| 添加文件夹入口 | 把文件夹本身作为一个入口 | 点击后在资源管理器中打开该文件夹 |
| 扫描文件夹 | 查找该文件夹内的可添加入口 | 批量整理某个软件目录 |
| 读取桌面 | 读取桌面上的候选入口 | 初次迁移桌面快捷方式 |
| 读取开始菜单 | 读取已安装程序的开始菜单入口 | 批量导入本机软件 |

读取后，检查候选列表，勾选要添加的项目，再点击"添加已选"。可以使用"全选"或"取消全选"。只扫描出列表还不等于已经加入面板。

### 两个扫描选项

- "包含子文件夹"决定是否继续查找下一级目录。
- "只扫描启动入口（过滤卸载、更新、辅助进程和网页书签）"会减少杂项，默认开启。

如果想添加文档、普通文件或被过滤的入口，优先用"选择多个文件"或直接拖入。不要因为扫描列表里没有文档，就判断文件已经丢失。

扫描有数量保护，单次最多处理约 2500 个候选、10000 个目录。超大目录建议按软件或子目录分批添加。系统链接和部分特殊目录可能不会递归扫描。

### 文件夹入口与扫描文件夹的区别

"添加文件夹入口"只增加一个文件夹图标，点击后打开文件夹。"扫描文件夹"是找出里面的程序或文件，供你逐项选择。想快速进入工作资料目录，使用前者；想把多个软件单独放进面板，使用后者。

### 重复入口与原路径

软件会尽量合并重复文件路径和指向同一目标的常见快捷方式。带不同启动参数的入口可能保留为不同项目。不要为了避免重复而删除真实文件。

入口依赖原路径。把原程序、文件夹、音乐或文档移动到别处后，应重新添加正确入口，或通过可用的编辑方式更新。玻璃板不会把所有原文件复制进自己的配置目录。

### 修改显示名称与图标

1. 右键入口，选择"修改名称与图标"。
2. 输入希望在玻璃板中显示的名称。
3. 选择图标图片，可使用 PNG、ICO、JPG、JPEG、BMP 等支持格式。
4. 保存并查看大面板和 Dock 的显示结果。

修改的是玻璃板内的显示信息，不会重命名磁盘上的真实文件。自定义图标会保存到配置相关目录；跨电脑迁移时用完整备份更稳妥。

## 07 分组批量整理与撤销

### 分组基础

"全部"显示所有入口，"未分组"显示尚未归入普通分组的入口。常见初始分组包括"创作""办公""游戏"。一个入口可以属于多个分组。

通过"更多"中的"管理分组"新建、重命名、调整或删除分组。名称不能与保留名称或已有名称重复，长度最多 32 个字符。

### 把入口加入分组

可以右键入口选择"移动到分组"，也可以拖到目标分组。拖动时在目标分组上停留约 0.7 秒，可切换过去再放下。

需要同一软件出现在多个分组时，在目标分组使用"添加已有图标"。这种方式添加的是已有入口的分组关联，不必再次扫描磁盘。

### 不同来源下的移动含义

- 从"全部"操作到某分组，通常是增加该分组关联，原有其他分组保留。
- 从一个具体分组移动到另一个具体分组，会移出当前来源分组，同时保留无关的其他分组关联。
- 在具体分组移除入口，只移除它与当前分组的关联。
- 在"全部"或 Dock 使用"移除入口"，会从玻璃板入口库及相关分组、Dock 中移除；真实磁盘文件不删除。

操作前先看当前分组标题。只想从 Dock 拿掉图标时，请用"取消 Dock 固定"。

### 批量选择

1. 点击"多选"，出现选择控件。
2. 勾选多个入口，可跨页保持选择。
3. 使用提供的批量移动、固定或移除操作；也可以一起拖动到目标位置。
4. 完成后退出多选。

非文本输入状态下，Ctrl+A 可选择当前筛选结果的全部入口，包括其他页；切换分组会清空当前选择。Delete 只应在多选操作语境下使用，删除前确认当前焦点和提示。

### 自动分组

"更多"中的"自动分组"主要处理尚未分组的入口，尽量保留已有人为整理的分组。识别依赖名称和规则，结果仍建议人工检查，尤其是自制软件、启动器和特殊命名文件。

### 删除分组会怎样

删除分组不会卸载软件，也不会删除真实文件。只属于这个分组的入口会回到未分组状态；仍属于其他分组的入口保留其他关联。

### 撤销和重做

在大面板"···"中使用"撤销·Ctrl+Z"和"重做·Ctrl+Y"。当前会话最多保留约 40 条相关整理历史。

撤销不是系统回收站，也不是所有设置的通用时光机。重启后历史不保留，应用方案或恢复备份会清理相关历史；笔记删除、真实文件操作不能指望用这里恢复。重要整理前先导出完整备份。

## 08 Dock 的常用软件与运行窗口

### 滚轮切换的是列表

鼠标移到 Dock 上：向上滚动切到常用软件，向下滚动切到正在运行的软件。滚轮不会直接依次激活每个程序窗口，仍需点击想打开或切回的图标。

常用列表保存你固定的入口；运行列表根据当前 Windows 窗口情况生成。没有可显示的运行窗口时，运行列表可能显示空态或占位内容。

### 固定常用软件

任选一种方式：在大面板右键软件选择"固定到 Dock"；把桌面或资源管理器入口拖到 Dock；在 Dock 右键菜单使用"添加软件或文件到 Dock"。

最多可固定 20 个用户入口。此电脑、设置、电源、网络、应用面板等系统入口不占这 20 个名额。屏幕宽度和可见数量设置可能让一部分入口收进"更多"，不代表固定失败。

### 点击后的行为

- 程序未运行时，点击固定入口会尝试启动。
- 识别到一个可切换窗口时，点击运行图标会切回该窗口；最小化窗口会尝试恢复。
- 同一程序有多个窗口时，可能弹出窗口列表，再选择具体窗口。
- Windows 焦点规则、管理员权限差异、某些启动器或特殊窗口类型可能影响识别和切换。

### 启动器和实际游戏窗口关联

如果固定的是启动器，但运行后需要切回游戏窗口：

1. 先正常打开启动器并进入目标程序或游戏。
2. 右键对应固定入口，找到"关联正在运行的窗口"。
3. 从当前运行窗口中选择真正需要关联的窗口。
4. 再点击 Dock 图标验证能否切回。

不再需要时可取消手动关联。右键中的"切换已打开的窗口"也可辅助选择已识别的窗口。关联不会安装插件到游戏中，也不能保证所有受保护窗口都能被 Windows 允许激活。

### 运行状态标记

"显示软件运行状态"控制常用图标上的运行标记。关闭标记后，滚轮切到运行列表的功能仍可使用。标记判断和实际窗口识别都可能受特殊程序结构影响。

### 三种移除不要混淆

| 操作 | 影响 |
|---|---|
| 取消 Dock 固定 | 只从常用 Dock 拿掉，面板和分组中的入口保留 |
| 移除入口 | 从玻璃板入口库及相关位置移除，真实文件保留 |
| 在 Windows 中卸载软件 | 删除或卸载真实软件，玻璃板无法代替卸载流程 |

## 09 Dock 排序居中位置与自动隐藏

### 把系统图标和软件混合排序

v0.9.12 支持将应用面板、此电脑、电源、Wi-Fi／蓝牙、设置与软件图标混合排列。

1. 先切到想整理的 Dock 页面：常用或正在运行。
2. 按住目标图标并拖动，观察插入位置标记。
3. 移到目标位置后松开，顺序会保存。
4. 系统图标也可右键使用"向前移动""向后移动"。

拖动过程中按 Esc、拖到无效区域或失去拖动捕获时，可能取消本次排序。正常拖动排序不会同时触发打开、关机或设置操作。

### 两页顺序分别保存

常用列表和正在运行列表各自记录顺序。在常用页调整设置图标，不代表运行页也会同步到同一位置；需要时分别调整。运行窗口关闭后会从运行列表消失，新窗口加入后再根据现有顺序协调显示。

暂时关闭某个系统图标再重新开启，会尽量保留它原来的排序位置。

### 调整 Dock 整体位置

1. 在 Dock 右键菜单勾选"允许自由拖动 Dock"，或在设置中解除 Dock 位置锁定。
2. 抓住 Dock 的拖动区域、背景或间隙，拖到需要的位置。
3. 放下后检查位置，再按需要锁定。

抓图标是在排序，抓背景或拖动区域是在移动整个 Dock。即使整体 Dock 锁定，图标排序仍可用。

### 居中与屏幕边缘

Dock 会以选定的中心位置应对常用列表、运行列表和图标数量变化，尽量避免宽度变化时整体偏移。手动移动后，以你选择的位置为基准；靠近屏幕边缘时，为了不让窗口越界会自动限制位置。

因此，想恢复屏幕水平居中，应使用设置中的居中或重置位置，而不是只把某一个图标拖到正中。屏幕边缘限制、可见图标数量和手动位置都会影响最终看到的结果。

### 对齐和位置参数

"Dock DIY"中可设置左、中、右对齐、水平偏移和底部距离。水平偏移约为 -500 至 500，底部距离约为 0–160。

已保存的手动位置可能优先于一般对齐设置。调整水平对齐会清理对应手动横向定位，调整底部距离会清理对应手动纵向定位。位置异常时优先重置，再选"居中"和需要的底部距离。

### Dock 自动隐藏

1. 在"Dock DIY"启用 Dock 自动隐藏。
2. 设置收起延迟，范围 200–3000 毫秒。
3. 设置底部唤出范围，范围 3–48 像素。
4. 移开鼠标等待收起，再把鼠标移到 Dock 所在显示器底边、与 Dock 对应的水平区域验证。

即使把 Dock 整体放得更高，底部唤出仍在其所在显示器的底边。不是整条桌面底边的任意位置都能唤出。打开菜单、设置、大面板或拖动时，Dock 会尽量保持可操作。

### 动效和尺寸

Dock 图标大小 32–64、图标间距 0–20、内边距 8–28、圆角 0–48、悬停放大约 1.0–1.6。可见用户入口数量可设置为 3–20，但还受屏幕可用宽度约束。

弹簧唤出效果需要相应开关与全局动效启用。全局动效强度约 0.5–1.5。开启动效并不意味着固定刷新率或对所有电脑保证完全相同的流畅度。

## 10 此电脑设置电源与网络快捷入口

### 开关系统图标

在设置"Dock DIY"中分别控制此电脑、设置、电源、Wi-Fi／蓝牙等入口。默认通常显示此电脑和设置；电源、网络属于按需开启的入口。

关闭设置图标后，可通过 Dock 空白处右键、托盘菜单或快捷键继续打开设置。不要因为齿轮消失而清空配置。

### 此电脑外观

此电脑支持"渐变徽章""简洁线框"等样式。Dock 的强调色可选晴空蓝、雾紫、薄荷绿、暖金、玫瑰粉、月光灰。强调色与组件文字色、玻璃底色是不同设置。

### 电源菜单

电源入口提供睡眠、重启、关机，并带确认步骤。这些操作会真实影响 Windows，会使正在进行的工作中断或进入睡眠；操作前保存文档。

不要把电源菜单当作测试动画的按钮。取消确认会取消相应电源操作。当前菜单没有提供可在手册中承诺的"锁屏"选项。

### Wi-Fi 和蓝牙菜单

可打开"系统快捷面板·Wi-Fi／蓝牙"、Wi-Fi 设置、蓝牙设置和网络设置。其中系统快捷面板通过 Windows 的相应快捷方式进入，实际界面可能随 Windows 版本变化。

这些是 Windows 入口，不是 GlassBoard 自行控制无线硬件的开关。电脑没有蓝牙、无线网卡被系统禁用、驱动异常或系统策略限制时，玻璃板不能替代硬件或驱动修复。

## 11 Windows 任务栏与桌面图标

### 先区分三种隐藏

| 功能 | 隐藏对象 | 鼠标移到边缘的结果 |
|---|---|---|
| 强制隐藏 Windows 任务栏 | Windows 自带任务栏 | 不一定会自动出现，需要恢复或切换开关 |
| Windows 任务栏自动隐藏 | Windows 自带任务栏 | 由 Windows 在边缘唤出 |
| Dock 自动隐藏 | GlassBoard 自己的 Dock | 按 Dock 的底部唤出区域出现 |

设置其中一种，不代表另外两种同时改变。排查时先说清消失的是 Windows 任务栏还是 GlassBoard Dock。

### 常见操作

- Ctrl+Alt+T：切换 Windows 任务栏强制隐藏与显示。
- Ctrl+Alt+D：切换 Windows 桌面图标隐藏与显示。
- Ctrl+Alt+H：切换 Windows 原生任务栏自动隐藏。
- Ctrl+Alt+R：恢复任务栏与桌面图标，并关闭 Windows 原生任务栏自动隐藏，便于找回完整桌面。

上述是默认快捷键，可在设置中更改、关闭，发生冲突时可能无效。托盘中也有同类菜单入口。

### 桌面图标隐藏后文件还在吗

隐藏只是改变桌面图标显示，不会删除桌面真实文件。在文件资源管理器中仍可访问相应桌面目录。需要找回显示时用恢复菜单，不必重新创建所有快捷方式。

### 紧急恢复

优先按 Ctrl+Alt+R。快捷键无效时，右键托盘选择"恢复任务栏与桌面图标"。仍无法找到入口或软件异常退出时，在完整程序目录运行 RestoreDesktop.cmd。

恢复工具会尝试通知正在运行的软件或执行独立恢复。不要先结束资源管理器、改注册表或删配置，这些通常不是必要的第一步。
