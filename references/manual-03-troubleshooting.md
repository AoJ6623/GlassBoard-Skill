# GlassBoard 玻璃板客户详细说明书（第 24~30 章）

## 24 找不到界面时的恢复顺序

### 大面板不见了

先按默认 Ctrl+Alt+Space，或点 Dock 的应用面板按钮。快捷键无效时用系统托盘"打开应用面板"。仍无响应时确认是否进入游戏模式，以及当前运行的是否为预期版本。

不要连续重复启动多个目录中的程序。窗口可能在屏幕外或被其他窗口遮住，应先尝试位置重置与游戏模式退出。

### Dock 不见了

1. 鼠标移到 Dock 所在显示器底边的对应水平区域，等待唤出。
2. 从托盘确认是否处于游戏模式，必要时退出；自动游戏模式持续触发时可先暂停自动检测。
3. 打开设置检查 Dock 自动隐藏和位置设置，必要时重置位置并居中。
4. 更换显示器或缩放后，确认窗口没有留在旧屏幕坐标。
5. 正常退出并从确认过的完整目录重新启动。

Windows 任务栏恢复功能主要针对 Windows 桌面元素，不能代替 Dock 位置和游戏模式检查。

### 某个组件不见了

先确认相应组件处于开启状态 → 确认没有游戏模式隐藏 → 检查全局置顶和遮挡 → 用"重新打开已启用组件"重建 → 必要时重置组件位置 → 检查文字不透明度、背景和无框设置。

只想找回一个组件时，不必直接运行"开启全部组件"。程序目录的 RecoverWidgets.cmd 会恢复并开启全部四类组件，执行前应知道其范围。

### 字看不见但组件可能还在

从设置进入目标组件 DIY，文字不透明度调到 100，选择明显对比色，恢复有框或默认外观。文字透明度为 0 时，背景也完全透明，就可能看起来像整个窗口消失。

### 所有位置乱了

先导出完整备份。分别重置大面板、Dock 和组件的位置，三者不是一个总开关。多显示器或 DPI 变化后重新摆放，再锁定需要的位置。

重置范围见第 29 章，避免为了找回一个窗口把所有个人数据清掉。

## 25 游戏模式后台占用与多显示器

### 手动游戏模式

系统托盘选择"进入游戏模式"，会隐藏 GlassBoard 界面，减少对全屏活动的干扰。退出时从托盘选择"退出游戏模式"。

游戏模式不是退出软件，也不等于把所有组件开关永久关闭。部分后台服务或提醒仍可能保留，不能把它理解为完全零后台占用。

### 自动游戏模式

自动检测属于可选功能，会把满足条件的全屏活动作为触发依据，可能包括全屏视频，不只游戏。如果看视频时 Dock 与组件消失，先检查这个选项。

需要恢复界面但仍保持全屏时，可从托盘暂停自动游戏模式，再退出当前游戏模式。游戏模式下，把鼠标移到底边不保证自动唤醒 Dock。

### 降低占用的实用顺序

1. 先关闭当前不需要的组件，尤其是音乐读取和天气联网。
2. 在外观设置降低模糊、反光、纹理、阴影等效果，观察画面与占用变化。
3. 关闭不需要的动效，减少悬停放大或唤出效果。
4. 避免同时打开多个播放器、多个壁纸程序或不必要的常驻工具，再做对照。
5. 保持同样壁纸、播放器、组件开关和等待时间，比较 CPU 与内存。

软件会对静态资源进行复用，并在音乐隐藏、暂停或无会话时降低读取频率。实际节省程度取决于环境，不承诺所有电脑固定占用多少 MB 或降低某个百分比。

### 如何看内存与 CPU

刚启动、第一次载入图标、打开设置、切换组件时出现短暂峰值不等于持续占用异常。先等待状态稳定，再观察一段时间，而不是只截取启动瞬间。

运行程序目录的 CheckMemory.cmd 可以生成约 30 秒采样结果，默认约每 2 秒记录一次，区分主程序和相关辅助进程。辅助进程的用途要结合当前功能判断，不建议在任务管理器里盲目逐个结束。

### 多显示器与缩放

目前是一套 Dock 和若干组件面板，不是每个显示器自动生成独立 Dock。Dock 与组件会尝试限制在可用屏幕范围，大面板主要按主屏工作区布局。

更换主屏、拔插显示器或改变缩放后，如果位置不合适，先用位置重置并重新摆放。不要为了一个窗口越界立即修改全系统缩放。不同 DPI、显卡和 Windows 版本的边缘行为仍需要实际核对。

## 26 诊断工具与向客服反馈

### 程序目录里的辅助工具

| 文件 | 用途 | 使用后的预期 |
|---|---|---|
| Start.cmd | 启动 GlassBoard | 打开程序 |
| RestoreDesktop.cmd | 恢复任务栏与桌面图标 | 桌面元素尝试恢复 |
| RecoverWidgets.cmd | 恢复并开启全部四类组件 | 时钟、天气、音乐、备忘录全部启用 |
| CollectDiagnostics.cmd | 收集诊断材料 | 桌面生成带时间的诊断 ZIP |
| CheckWindows.cmd | 在实际 Windows 环境执行自检 | 程序目录出现检查结果文本 |
| CheckMemory.cmd | 记录主程序和辅助进程占用 | 程序目录出现采样 CSV |

脚本应从完整用户包运行，不要从陌生帖子下载同名脚本替换。程序目录不能写入或系统策略阻止脚本时，记录提示，不要默认提升为管理员或放宽全系统脚本策略。

### 收集诊断包

运行 CollectDiagnostics.cmd，完成后在桌面查找类似 GlassBoard_Diagnostics_时间.zip 的文件。包内可能包含错误、会话、更新日志及布局、历史副本、移除记录等已存在文件。

当前诊断脚本不会自动把完整备忘录正文数据作为常规附件打包。布局和日志仍可能包含软件名、用户目录、文件路径等个人信息，分享前检查，建议私下交给支持人员，不要直接公开发布。

### Windows 自检

运行 CheckWindows.cmd，可生成 self-test-result.txt、WindowsCheck-result.txt 等结果。部分检查可能短暂创建探测窗口。

通过自检只能说明覆盖的检查项通过，不等于所有播放器、游戏、显示器和网络服务均已验证。出现失败时保留完整结果，不必先反复重装。

### 推荐的完整反馈模板

- 问题一句话：例如"切到运行列表后 Dock 在第二屏偏到左侧"。
- 软件实际版本和启动路径：从 EXE 属性或音乐诊断核对。
- Windows 版本：Windows 10／11，能提供系统版本号更好。
- 显示器：数量、主屏、分辨率、缩放比例，是否刚拔插。
- 复现步骤：从什么状态开始，依次点击或拖动了什么。
- 预期结果：希望看到什么。
- 实际结果：出现什么，是否每次必现。
- 最近变化：更新、移动目录、恢复方案、换播放器、改城市等。
- 相关材料：截图、错误原文、发生时间、必要的诊断包。
- 是否有可用备份：大概日期，以及是否包含重要笔记。

先描述一个最容易稳定复现的问题，再附材料。只有"有 bug"而没有操作步骤，AI 或客服很难区分配置、网络、播放器条件和程序缺陷。

## 27 常见问题与直接处理

以下问题编号可直接发给 AI，例如"请按 Q24 帮我排查，但一次只给一步"。如果回答涉及恢复备份或删除内容，先确认当前重要数据已经保存。

### 安装和入口

**Q01 双击没反应，先做什么？**
确认 ZIP 已完整解压，程序依赖文件保留，系统满足运行条件。查看托盘是否已经在运行，再从同一完整目录用 Start.cmd 启动并记录提示。不要先反复复制单个 EXE 或启动多个旧目录。

**Q02 我下载了新版，怎么界面还像旧版？**
检查正在启动的路径及 GlassBoard.exe 文件版本。正常退出托盘旧实例，再运行新目录，并修改桌面快捷方式和开机启动。下载完成不等于当前进程已经换成新版本。

**Q03 关闭大面板后软件是不是退出了？**
不是。大面板收起后，Dock、组件和托盘可能继续工作。完整退出用托盘"退出 GlassBoard"。

**Q04 为什么开始菜单导入后有些软件没出现？**
扫描过滤、快捷方式结构、候选上限或软件没有开始菜单入口都可能影响结果。用"选择多个文件"或直接拖入目标快捷方式，核对候选列表后点击添加。

**Q05 添加文件夹后只出现一个图标正常吗？**
正常，"添加文件夹入口"就是添加文件夹本身。想列出内部程序，使用"扫描文件夹"，勾选候选后添加。

**Q06 原文件移动后点不开怎么办？**
用"打开文件所在位置"核对路径，重新添加新位置的入口。玻璃板不托管原程序或文档，备份布局也不会把真实文件搬到新路径。

**Q07 改了入口名称，真实文件会改名吗？**
不会，只改玻璃板中的显示名称。想重命名真实文件，需要在 Windows 文件管理中操作，同时注意入口路径可能受影响。

**Q08 添加了重复的软件怎么办？**
先查看是否同一目标、不同启动参数或不同快捷方式。确认多余项后移除玻璃板入口；不要为去重删除磁盘程序文件。

### 面板和分组

**Q09 搜索不到已添加的软件？**
切到"全部"，清空搜索后核对，再输入较短名称。当前分组与搜索共同筛选，软件可能在其他分组或另一页。

**Q10 关掉分组栏后分组丢了吗？**
没有。重新显示分组栏即可。隐藏时显示全部入口，不是删除分组数据。

**Q11 一个软件想同时放进办公和创作？**
进入目标分组用"添加已有图标"。不必再次扫描或复制真实软件。

**Q12 删除一个分组会卸载里面的软件吗？**
不会。失去唯一分组的入口回到未分组，真实文件不受影响。

**Q13 为什么从某分组移除后，在全部里还能看到？**
具体分组里的移除通常只取消分组关联。若要从整个玻璃板入口库移除，在"全部"核对后操作。

**Q14 Ctrl+Z 为什么恢复不了昨天的整理？**
撤销历史属于当前会话，重启后不保留，而且不是所有数据的恢复工具。查完整备份和"找回旧版入口与分组"。

### Dock

**Q15 滚轮为什么没有直接切到下一个软件窗口？**
滚轮用于切换常用和运行列表，向上常用、向下运行。切到列表后再点击目标图标激活窗口。

**Q16 切换列表时 Dock 还是看起来不居中？**
先确认 v0.9.12 和当前显示器，重置 Dock 位置，选择居中，检查手动偏移、屏幕边缘和可见数量。仍可复现时提供切换前后截图与显示器缩放，不要只拖一个图标修整体位置。

**Q17 拖动图标时为什么整个 Dock 没移动？**
图标拖动是排序。移动整体要解锁 Dock 后抓背景、间隙或拖动区域。

**Q18 Dock 锁定后还能调图标顺序吗？**
可以。整体位置锁定与内部图标排序是两件事。

**Q19 常用页排好了，运行页怎么还是另一顺序？**
两个列表分别保存顺序。在运行页再调整一次；窗口开关也会影响运行列表内容。

**Q20 设置或此电脑能放在软件中间吗？**
可以。v0.9.12 支持系统图标与软件混合拖动排序，系统图标还可以右键前移或后移。

**Q21 设置图标关掉后怎么再打开设置？**
Dock 空白处右键"外观设置"、托盘"外观与快捷键"或 Ctrl+Alt+S。Dock 右键还可直接显示设置图标。

**Q22 固定了很多软件，为什么一部分不显示？**
检查可见数量、屏幕宽度和"更多"入口。最多固定 20 个用户入口，但不保证全部在一排同时可见。

**Q23 我只想从 Dock 拿掉，不想从面板删除？**
使用"取消 Dock 固定"，不要选"移除入口"。

**Q24 点击游戏图标只打开启动器，切不回游戏？**
先让游戏窗口运行，再右键固定入口"关联正在运行的窗口"，选择实际游戏窗口，随后验证。管理员权限或受保护窗口仍可能限制激活。

**Q25 Dock 自动隐藏后鼠标移到底部没反应？**
确认是 Dock 所在显示器、对应水平范围，适当增加底部唤出范围；再检查游戏模式。整个屏幕底部的任意点不一定都是唤出区。

**Q26 关闭运行标记后还能看运行软件吗？**
可以，标记开关与滚轮运行列表独立。

### 系统桌面和组件

**Q27 Windows 任务栏不见了怎么办？**
先按 Ctrl+Alt+R，或托盘"恢复任务栏与桌面图标"。失败时用完整程序目录的 RestoreDesktop.cmd，按第 11 章操作。

**Q28 桌面图标隐藏后是不是文件没了？**
不是，先恢复图标显示。不要在没有核对文件资源管理器前重建或删除桌面内容。

**Q29 无框后组件拖不动？**
先解除全局组件锁定，再抓非按钮、非输入框的文字区域。仍不便移动时临时恢复有框，移动完成再无框。

**Q30 组件字体改成透明后找不到了？**
从设置进入目标 DIY，文字不透明度调到 100，选择对比色，必要时恢复默认外观。不要只改背景透明度。

**Q31 开了无框怎么备忘录还有输入框？**
无框移除装饰外壳，输入框是必要功能控件，仍会保留。音乐按钮、天气刷新等也不会全部消失。

**Q32 时钟无框后，融合在一起的外壳也变化了？**
融合组件共享容器外壳，其中无框会影响共享外壳。需要完全独立控制时分到不同 A–D 面板。

**Q33 怎么一键统一四个组件文字色？**
在目标 DIY 设置好颜色、不透明度和阴影，再用"配色应用到全部组件"。它不复制时钟字体或音乐样式。

**Q34 只开启时钟，为什么恢复后四个都出来了？**
可能用了"恢复并开启全部组件"或 RecoverWidgets.cmd。只重建已开启的组件应使用"重新打开已启用组件"。

**Q35 设置里锁定组件，为什么所有组件都锁了？**
这是当前全局组件锁定的设计。不是每个小组件独立锁定。

**Q36 文字颜色改了却没变化？**
确认 DIY 下拉选择的是正确组件、六位色值有效、已点击"应用色值"，并且文字不透明度不为 0。区分文字色、玻璃底色和 Dock 强调色。

### 时钟和提醒

**Q37 时钟为什么有英文星期？**
部分样式将英文星期作为排版元素。换其他样式查看，不必因此更改 Windows 语言。

**Q38 选择字体后没生效？**
点击"应用字体"，确认该字体已经安装且含所需字形。字体缺字时可能由系统回退。

**Q39 日程轨道能显示我的日历任务吗？**
不能按当前功能承诺。它展示本地一天的时间推进，不连接个人日历或待办列表。

**Q40 分栏数字为什么没有翻页动画？**
它是分栏视觉排版，不是持续翻页组件。不要把没有翻页动画当作播放失败。

**Q41 指针钟没有秒针是不是卡住了？**
当前样式主要按分钟信息更新，没有连续秒针。先观察分钟变化，并核对系统时间。

**Q42 闹钟设置过去的时间为什么没立刻响？**
当天时间已过去时会安排到下一天。用未来几分钟的测试时间验证，并保持软件运行、电脑唤醒。

**Q43 关闭时钟会把闹钟删除吗？**
不会等同于删除提醒，但整个软件退出、电脑睡眠期间不能保证按时提醒。管理闹钟应在提醒列表中启用、关闭或删除。

**Q44 能设置手机那种自定义歌曲闹铃吗？**
当前没有相应 MP3 闹铃选择入口，使用系统提示声。不要让 AI 虚构该设置。

### 天气

**Q45 改城市以后还显示旧天气？**
确认点击"应用天气城市"，再刷新并等待查询。查看是否显示上次数据，按第 17 章核对城市与网络。

**Q46 城市名正确，天气像另一个地方？**
名称正确不等于地理解析正确。尝试明确的城市加国家或省州，必要时输入正确的纬度、经度。

**Q47 天气标题出现站点名或英语？**
先核对版本和城市输入，当前尽量显示用户输入的城市名。上游返回与特殊地名仍可能不同，提供截图与原始城市输入，不要只凭标题判断数据地点。

**Q48 能看空气质量和七天预报吗？**
本手册没有对应的内置操作入口。需要更多天气信息时查看独立天气服务，不要在当前界面中寻找虚构按钮。

### 音乐

**Q49 歌在播放，组件却说没有媒体？**
核对系统模式、播放器的系统媒体支持、当前是否真正播放，再用"查看音乐读取状态"收集结果。并非所有声音来源都提供媒体会话。

**Q50 为什么显示浏览器的视频而不是音乐播放器？**
多个来源可能争用系统媒体会话。先暂停或关闭浏览器媒体，用单一播放器测试，再看诊断里的来源。

**Q51 播放按钮能用，下一首不能用？**
播放器可能不提供下一首能力，或当前没有可切换曲目。先在播放器本身验证下一首，再检查组件模式；某些流媒体或网页限制属于来源能力。

**Q52 怎么拖动歌曲进度？**
当前组件没有可按说明操作的进度滑块，请在原播放器中拖动。AI 不应引用旧版文字编造当前步骤。

**Q53 如何调本地音乐音量？**
设置"桌面组件"中的"本地音乐音量"，0–1。系统播放器音量请到播放器或 Windows 音量混合器调整。

**Q54 本地文件加入了但播放不了？**
确认文件仍在原位置、没有损坏，双击列表项或"播放已选"，再用 Windows 可用播放器验证解码。文件后缀受支持不等于所有编码可解码。

**Q55 封面为什么是播放器图标？**
来源可能没有提供专辑图片，组件使用替代图。检查自动补充封面开关与来源状态，不保证每首都有匹配封面。

**Q56 五种音乐按钮皮肤会增加功能吗？**
不会，只改变样式，仍是上一首、播放或暂停、下一首。

**Q57 关闭音乐组件后歌还在响？**
系统模式下播放器是独立程序，去原播放器暂停。本地模式关闭组件会释放本地播放，先确认当前模式。

### 笔记方案和数据

**Q58 关闭备忘录后笔记没了吗？**
没有，重新开启并从下拉列表选择。若数据确实异常，先备份配置并停止反复覆盖，再检查历史保护和备份。

**Q59 删除的笔记能 Ctrl+Z 恢复吗？**
不能依赖大面板撤销。查你自己的 TXT 导出或完整备份，恢复前先备份当前内容。

**Q60 清单方框怎么不能像待办软件那样用？**
当前清单主要插入文本标记，不是完整任务管理系统。可以直接编辑文字，不要假设存在任务完成状态和通知。

**Q61 把外观方案发给朋友，软件为什么打不开？**
方案没有打包真实应用，对方安装路径也可能不同。让对方重新选择本机入口，方案用于搭配分享。

**Q62 外观方案和完整备份选哪个？**
切换或分享视觉搭配用方案；迁移自己的笔记、布局和整体配置用完整备份。两者都不替代真实文档和软件的备份。

**Q63 恢复备份后快捷键不一样？**
可能遇到本机快捷键冲突而保留了可用旧设置。进入"快捷键与开关"重新核对并保存。

**Q64 想找回很久以前的分组？**
尝试"通用"中的"找回旧版入口与分组"，或已有完整备份。历史有数量与存在条件限制，没有保存过的数据无法凭空重建。

### 更新性能和系统条件

**Q65 开机不自动启动？**
确认通用设置启用，当前程序目录没移动，再检查 Windows 启动管理。路径换过时在新目录关闭后重新开启，不要同时运行多个旧版。

**Q66 更新失败先做什么？**
记录错误与连接诊断，核对系统代理或直接连接、程序目录可写和更新助手完整。必要时完整下载官方用户包，先退出旧实例再手动更新。

**Q67 看全屏视频时所有组件没了？**
检查自动游戏模式，它可能把全屏视频也识别为全屏活动。先暂停自动检测，再退出游戏模式。

**Q68 游戏模式为什么还有后台占用？**
它主要隐藏界面和减少干扰，不是退出程序。需要进一步减少占用时关闭不需要的组件，完全停止则正常退出软件。

**Q69 内存比别人截图高是不是坏了？**
不一定。入口图标数量、组件、播放器、运行时长、壁纸和采样时机都会影响。先固定条件用 CheckMemory.cmd 记录，再判断是否持续增长或异常高 CPU。

**Q70 换显示器后窗口跑偏？**
先重置对应 Dock、面板或组件位置，重新摆放。记录屏幕数量、主屏和缩放，必要时重启软件验证；不要直接删全部配置。

**Q71 AI 说的按钮我找不到？**
提供当前版本、实际设置页面与截图，让 AI 只用本手册真实入口。特别提醒音乐进度、随机循环、世界时钟等不能因 AI 猜测就认为存在。

**Q72 自检通过是否代表一定没 bug？**
不是。自检只覆盖特定检查项。可重复的实际问题仍应提供步骤和环境，让支持人员核对。

## 29 重置和恢复操作的影响范围

| 操作 | 会改变什么 | 不应误认为 |
|---|---|---|
| 收起大面板 | 只改变面板可见状态 | 退出程序 |
| 关闭一个组件 | 关闭该组件，保存其相关数据 | 删除笔记或卸载组件 |
| 取消 Dock 固定 | 移除常用 Dock 固定关系 | 从所有分组删除或卸载软件 |
| 移除入口 | 影响入口库或当前分组，取决于操作位置 | 删除磁盘真实文件 |
| 恢复本组件默认外观 | 恢复当前组件样式 | 清空笔记或重置全部窗口位置 |
| 配色应用到全部组件 | 复制文字色、不透明度、阴影 | 复制字体、所有样式和面板编号 |
| 无框状态应用到全部组件 | 复制是否无框 | 删除功能按钮和输入区域 |
| 重置全部组件位置 | 清理布局及部分面板覆盖值 | 只改两个坐标，或清空笔记 |
| 重新打开已启用组件 | 重建目前启用的组件 | 开启全部四类 |
| 恢复并开启全部组件 | 开启全部四类并尝试恢复展示 | 只恢复原来开着的一类 |
| 应用外观方案 | 切换搭配及有关入口布局 | 完整数据恢复或安装软件 |
| 恢复完整备份 | 加载备份配置和个人数据 | 把真实项目、应用、音乐复制回来 |
| Ctrl+Alt+R | 恢复 Windows 桌面元素并关闭原生任务栏自动隐藏 | 重置 Dock 和所有组件外观 |
| 正常退出 GlassBoard | 结束程序并保存，尝试恢复桌面 | 删除用户配置 |

不确定影响范围时，先导出完整备份，再执行最小范围的恢复。窗口位置问题优先重置位置，文字看不见优先恢复文字，不必清空全部配置。

### 网络和数据应如何理解

当前使用本机配置，不要求 GlassBoard 云账号，也不提供内置跨设备云同步。天气会把所填城市或解析位置用于向天气服务查询，在线更新会访问项目发布与相关下载服务；打开的第三方播放器、程序或链接有自己的网络行为。

把说明书上传 AI 不会把电脑里的全部个人配置自动传给 AI。只有你主动附上的截图、文本、诊断包，或另行明确授权的工具能够提供额外信息。AI 不能凭这份说明书看到屏幕或知道当前开关状态。

### 哪些情况需要补充信息

界面与手册不一致时补版本和截图；窗口位置问题补显示器与缩放；天气问题补城市原文、提示与发生时间；音乐问题补模式、播放器名和音乐读取状态；启动或更新问题补实际路径和完整错误；数据问题先备份，再说明最后正常时间和最近操作。

### AI 应避免的错误回答

- 不把计划中的功能、历史截图或其他桌面插件的能力当作当前功能。
- 不编造音乐进度条、随机循环开关、独立世界时区、天气空气质量或在线歌词入口。
- 不声称外观方案会安装朋友电脑上的软件，或完整备份会包含所有真实文档。
- 不声称无框会删除所有按钮，或组件锁定是每个组件单独设置。
- 不把某个网络服务失败直接归因于软件损坏，不把播放器不提供数据直接说成电脑没有声音。
- 不在没有证据时承诺百分之百兼容、固定占用或所有提醒都能在睡眠中唤醒。
- 不把删除配置、结束系统进程、关闭安全防护、改注册表作为常规第一步。
- 不把"用户希望实现"当成"当前已经支持"，不把"需要核对"当成"已经确认"。

### 文档适用范围

本手册覆盖 v0.9.12 的客户操作和已知能力边界，不替代对具体 Windows、播放器、硬件或网络服务的现场验证。发现与当前界面不一致时，以核对后的实际版本为起点，保留问题步骤，反馈给支持人员修订。

客户可以直接从一句话开始询问 AI："我已经上传玻璃板说明书，请先确认我想做什么，再只用当前版本有的功能一步一步教我。"
